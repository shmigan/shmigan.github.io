Privacy Policy

Last updated: October 10, 2026

shmiga agent is a private application used only by its owner to work with the owner's own Google account. It has no other users.

What data the application accesses

With the owner's consent, the application accesses the owner's Google Drive, Google Sheets, Google Docs and Gmail (reading messages and sending messages the owner has approved).

How the data is used

The data is used only to perform tasks requested by the owner. It is not sold, not shared with third parties and not used for advertising.

Storage

Access keys are stored on the owner's private server. Downloaded files are kept temporarily and deleted automatically within 7 days.

Revoking access

Access can be revoked at any time in Google Account settings: Security → Third-party apps with account access → shmiga agent → Remove access.

Google API Services User Data Policy

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
